# Branch-Compare

Select to which branch git compares to display its colordecorations.

## Features

Select a branch to which git colordecorations should compare to.
You can select a different branch foreach local branch you have.

## Extension Settings

This extension contributes the following settings:

* `branchCompare.baseRefs`: Dictionary of your local branch and the remote branch to compare against.
* `branchCompare.autoFetch`: Auto 'git fetch' the base ref before computing changes.
